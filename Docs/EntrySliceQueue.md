# Ближайшие 18 PR для Входного контура

План обновлён 24 ноября 2026 г. после повторного просмотра личной библиотеки Fab. Цель очереди — дать новому игроку запустить игру, понять приборы скафандра, пройти четыре камеры и самостоятельно пополнить кислород на первой станции. Ориентир из дорожной карты — 20–25 минут. Фактическое время нужно измерить с четвёртой камерой. Позиции ниже обозначают порядок работ, номера GitHub появятся при открытии PR.

За основу взяты утверждённый «Бортовой стенд», работающий EQP‑01 на левом запястье, существующие сохранения, учебные камеры и кислородная стойка. Вопросы владельцу определяют оформление проекции, разделение показаний между приборами и способ управления. По готовности ответов можно начинать позиции 2–7. Начать можно с позиции 1; образец окружения (9) опирается на её замеры. Для замены художественных ассетов на этом этапе используются только позиции личной библиотеки Fab.
