# Стенд движения

Стенд создаёт 24 дорожки в тестовом режиме `MovementLabGameMode` и использует тот же контроллер первого лица, что и учебная камера. Площадки состоят из серых мешей с отдельными прямоугольными коллизиями. Ширина дорожки 7 м, длина разгона перед ступенью, уступом или разрывом 12 м.

## Запуск

Соберите `AbandonedEditor Win64 Development` по [инструкции в README](../Readme.md#запуск-на-windows). Из корня проекта запустите отдельное игровое окно.

```powershell
$ueRoot = 'C:\Program Files\Epic Games\UE_5.7'
$project = (Resolve-Path .\Abandoned.uproject).Path
$map = '/Engine/Maps/Entry?game=/Script/Abandoned.MovementLabGameMode'
& "$ueRoot\Engine\Binaries\Win64\UnrealEditor.exe" $project $map -game -log -windowed -ResX=1280 -ResY=720
```

При проверке конфигурации запускайте команду как есть. В `Saved/Logs/Abandoned.log` найдите выбор Vulkan RHI, имя фактического GPU и строку `Movement Lab ready: 24 trials, gravity -2000 cm/s^2.` Флаг `-vulkan` позволяет повторить запуск с явным выбором RHI для диагностики.

## Управление и измерения

| Клавиши | Действие |
| --- | --- |
| WASD, мышь | Движение и обзор |
| Space | Прыжок |
| Левый Shift / левый Alt | Спринт / медленный шаг при удержании |
| Левый Ctrl | Приседание. Для duck-jump сначала прыгните, затем нажмите Ctrl в воздухе. |
| Q / E | Предыдущая / следующая дорожка |
| R | Возврат на старт текущей дорожки. После падения возврат происходит автоматически. |
| M | Меню проверки с возвратом в учебную камеру. |

HUD показывает дорожку, текущую скорость, расстояние по X до края разгона и высоту центра капсулы. После прыжка HUD и журнал `LogMovementLab` показывают поверхность приземления или падение, измеренную высоту центра капсулы над точкой отрыва, горизонтальное смещение и скорость отрыва. При падении смещение учитывает полёт до автоматического сброса. Это измерение полезно для сравнения попыток с одинаковыми условиями.

| Дорожки | Что проверить |
| --- | --- |
| 1. Ровный пол | Прыжок с места. Запишите вершину траектории. Исходная расчётная высота 90 см при скорости отрыва 600 см/с по вертикали. |
| 2–4. Ступени 25, 30 и 35 см | Идите прямо без прыжка. Запишите наибольшую ступень с результатом `Reached target on foot`. |
| 5–16. Уступы 50, 70, 80, 90, 100, 110, 120, 135, 150, 160, 170 и 180 см | Для каждого сравните обычный прыжок и приседание в полёте. Успех обозначается `Landed on target`. |
| 17–23. Разрывы 400–700 см с шагом 50 см | Разгонитесь до 800 см/с. Проверьте поздний прыжок у края, диагональный заход и приседание в воздухе. |
| 24. Разрыв 600 см с пониженной площадкой | Повторите тот же разгон. Площадка за разрывом на 100 см ниже точки отрыва. Запишите результат отдельно от разрыва на одном уровне. |

В протокол запишите версию UE, частоту кадров, дорожку и приём, скорость отрыва, высоту, дальность и исход. Для расчёта размеров камер используйте повторяемые результаты с запасом. См. [исходные метрики и критерии первого среза](Design.md#исходные-метрики-для-ue5).

## Результаты

UE 5.7.4, Windows x64, Vulkan SM5, RTX 4070 Ti SUPER. Выполнено **60 попыток на каждом шаге симуляции**, 1/60 и 1/120 с. Во всех 60 парах совпал исход. Уступы проходили с разбегом 510 см/с и отрывом примерно за 108–115 см до передней грани. Разрывы проходили с разбегом 800 см/с и отрывом примерно за 7,5–10,4 см до края. Диагональный заход составлял 12°, приседание начиналось после отрыва.

| Испытание | Результат при обоих шагах |
| --- | --- |
| Прыжок с места | Вершина траектории центра капсулы на **90,0 см** выше точки отрыва. |
| Ступени | 25 и **30 см** пройдены шагом. 35 см остановили игрока. |
| Уступы, обычный прыжок | До **110 см** включительно. 120 см и выше остановили игрока. |
| Уступы, приседание в полёте | До **150 см** включительно. 160 см и выше остановили игрока. |
| Разрывы 4,0–5,0 м, равные площадки | Пройдены всеми четырьмя вариантами. |
| Разрыв **5,5 м**, равные площадки | Пройден с приседанием в полёте при прямом и диагональном заходе. |
| Разрывы 6,0, 6,5 и 7,0 м, равные площадки | Все четыре варианта закончились падением. |
| Разрыв 6,0 м, посадка на 1 м ниже | Пройден всеми четырьмя вариантами. |

Высота борта учитывает форму капсулы и контакт её нижней части с краем. Поэтому проверенный уступ 110 см сочетается с подъёмом центра капсулы на 90 см. Для блокаута начинайте с типовой ступени 25 см и разрыва до 4,5 м, если прыжок обязателен. Для задачи, которая требует куба, 150 см уже доступны с приседанием. 160 см и выше проверяйте на конкретных краях и с запланированным разбегом.

Для повторения добавьте к команде запуска `-benchmark -fps=60 -MeasureMovementLab`, затем повторите с `-fps=120`. Окно закроется после строки `Movement Lab measurements complete.` В журнале `LogMovementLab` сохраняются строки `Measurement` с исходом, скоростью отрыва, запасом до края и фактом приседания в воздухе.
