# Стенд движения

Стенд создаёт геометрию и контроллер первого лица в тестовом режиме `MovementLabGameMode`. Площадки состоят из серых мешей с отдельными прямоугольными коллизиями. Ширина дорожки 7 м, длина разгона перед ступенью, уступом или разрывом 12 м.

## Запуск

Соберите `AbandonedEditor Win64 Development` по [инструкции в README](../Readme.md#запуск-на-windows). Из корня проекта запустите отдельное игровое окно.

```powershell
$ueRoot = 'C:\Program Files\Epic Games\UE_5.7'
$project = (Resolve-Path .\Abandoned.uproject).Path
$map = '/Engine/Maps/Entry?game=/Script/Abandoned.MovementLabGameMode'
& "$ueRoot\Engine\Binaries\Win64\UnrealEditor.exe" $project $map -game -log -windowed -ResX=1280 -ResY=720
```

При проверке конфигурации запускайте команду как есть. В `Saved/Logs/Abandoned.log` найдите выбор Vulkan RHI, имя фактического GPU и строку `Movement Lab ready: 20 trials, gravity -2000 cm/s^2.` Флаг `-vulkan` позволяет повторить запуск с явным выбором RHI для диагностики.

## Управление и измерения

| Клавиши | Действие |
| --- | --- |
| WASD, мышь | Движение и обзор |
| Space | Прыжок |
| Левый Shift / левый Alt | Спринт / медленный шаг при удержании |
| Левый Ctrl | Приседание. Для duck-jump сначала прыгните, затем нажмите Ctrl в воздухе. |
| Q / E | Предыдущая / следующая дорожка |
| R | Возврат на старт текущей дорожки. После падения возврат происходит автоматически. |

HUD показывает дорожку, текущую скорость, расстояние по X до края разгона и высоту центра капсулы. После прыжка HUD и журнал `LogMovementLab` показывают поверхность приземления или падение, измеренную высоту центра капсулы над точкой отрыва, горизонтальное смещение и скорость отрыва. При падении смещение учитывает полёт до автоматического сброса. Это измерение полезно для сравнения попыток с одинаковыми условиями.

| Дорожки | Что проверить |
| --- | --- |
| 1. Ровный пол | Прыжок с места. Запишите вершину траектории. Исходная расчётная высота 90 см при скорости отрыва 600 см/с по вертикали. |
| 2–4. Ступени 25, 30 и 35 см | Идите прямо без прыжка. Запишите наибольшую ступень с результатом `Reached target on foot`. |
| 5–12. Уступы 50, 70, 80, 90, 100, 120, 135 и 150 см | Для каждого сравните обычный прыжок и приседание в полёте. Успех обозначается `Landed on target`. |
| 13–19. Разрывы 400–700 см с шагом 50 см | Разгонитесь до 800 см/с. Проверьте поздний прыжок у края, диагональный заход и приседание в воздухе. |
| 20. Разрыв 600 см с пониженной площадкой | Повторите тот же разгон. Площадка за разрывом на 100 см ниже точки отрыва. Запишите результат отдельно от разрыва на одном уровне. |

В протокол запишите версию UE, частоту кадров, дорожку и приём, скорость отрыва, высоту, дальность и исход. Для расчёта размеров камер используйте повторяемые результаты с запасом. См. [исходные метрики и критерии первого среза](Design.md#исходные-метрики-для-ue5).
