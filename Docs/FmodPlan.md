# FMOD для входного контура и станции

Первый результат — слышимый щелчок конкретной плиты и ответ привода в упакованном Button. Текущее дыхание после падения уже воспроизводит компонент UE в `VanguardRoute`. Сценарий `VanguardFallsAudio` проверяет декодирование. Он останется контрольным примером при сравнении двух реализаций. Интеграция запланирована.

| Этап | Работа | Критерий приёмки |
| --- | --- | --- |
| 1. Сборка | Выбрать одну совместимую версию FMOD Studio, интеграции 2.03 для UE 5.7 и библиотек Windows Desktop. Зафиксировать патч, контрольные суммы и способ получения SDK на чистом доверенном runner. Собрать Editor и Win64 на исходной UE 5.7.4. Выпустить тестовый банк из Studio, включить его и runtime DLL в пакет. | На машине без Studio запускается игра из архива, событие из банка слышно и отображается в профилировщике. Проверить Development и Shipping. |
| 2. Пилот Button | Адаптер в Infrastructure наблюдает смену состояний плит A/B, реле и створки. Позиционный щелчок принадлежит конкретной плите. Для мотора предусмотреть начало движения, петлю, остановку и зажим. За звук отвечает смена состояния один раз, включая сброс R. | Пройти оба решения. При удержании куба на плите щелчок звучит один раз. При зажиме и сбросе петля заканчивается. В тишине игрок считывает те же состояния по плитам и индикации. |
| 3. Жизненный цикл | Общий банк скафандра живёт с игровой сессией. Банк устройств подготавливается асинхронно вместе с камерой. Входящий уровень молчит до активации. При отмене загрузки или уходе остановить эмиттеры камеры, снять подписки и освободить банк после последнего пользователя. Короткий сигнал сохранения привязать к успешной публикации слота. | Два последовательных прохода, ранний выход, сброс и восстановление слота. В отложенном запросе нет раннего сигнала сохранения. После выгрузки нет голосов ушедшей камеры. При отсутствующем банке шлюз и сохранение продолжают работать. |
| 4. Станция и выпуск | Перенести дыхание, клапан кислорода и запись в три группы микшера. Состояние скафандра определяет интенсивность дыхания. Реплике дать приоритет над выпуском воздуха. Сохранить регулировку громкости, отключение звука, паузу и текстовый эквивалент обязательных сигналов. | Прослушать в наушниках и стерео. Повторить VanguardFallsAudio с измерением воспроизведения новым адаптером. Сравнить с исходным пакетом p95/p99 кадра, CPU микшера, пики RAM, число голосов и размер архива. |

Игровое состояние, идентификаторы Save v2 и решение об открытии шлюза принадлежат C++-системам. C++-порт нужен там, где сценарий публикует событие для внешнего воспроизведения. Ссылки на банки, GUID событий и вызовы FMOD принадлежат адаптеру UE. Для пилота достаточно собственных механических шумов с зафиксированным происхождением. [Интеграция для UE 5.7](https://github.com/fmod/fmod-for-unreal/tree/2.03-UE5.7) · [Руководство по банкам, размещению в пространстве и упаковке](https://www.fmod.com/docs/2.03/unreal/user-guide.html)

## Библиотеки для первого звукового прохода

Для пробы в Button и Balance начать с Garage Foley и The Warehouse. Отобрать короткий контакт металла для плиты, отдельный щелчок отпускания и три фрагмента привода для пуска, хода и остановки. Для станции добавить комнатный фон из World Sounds. Каждую запись оценить в движении персонажа и в тишине у двери. Отбор ниже сделан по каталогам издателей 22 ноября 2026 года. Прослушивание в игре и выбор конкретных файлов входят в пилот.

Подготовить 2–3 варианта нажатия и более тихое отпускание. Источник движется вместе с площадкой. | Бесплатно. 100 стереоэффектов в 32-bit WAV. **Как собрать банки.** Исходные записи импортируются в FMOD Studio. События плит, реле и привода назначаются в `ChamberDevices`, дыхание — в `Suit`, фон и кислородный клапан — в `Vanguard`. Для каждой принятой записи зафиксировать исходное имя, автора, лицензию, дату получения и назначение в событии. Лицензированные исходники хранить в доступном команде хранилище с учётом числа мест. Из проекта Studio собирать собственные банки для Windows и проверять их внутри игры. [Импорт звуков в Studio](https://www.fmod.com/docs/2.03/studio/managing-assets.html) · [Упаковка банков для Unreal](https://www.fmod.com/docs/2.03/unreal/user-guide.html)
