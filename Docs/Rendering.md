# Графический профиль и рекомендованная конфигурация

## Минимальные требования игры

| Компонент | Целевая минимальная конфигурация |
| --- | --- |
| ОС | Windows 10 или 11, 64-разрядная |
| Процессор | Intel Core i7-3770 или AMD FX-9590 |
| Видеокарта | NVIDIA GeForce GTX 1060 или AMD Radeon RX 480, от 3 ГБ видеопамяти |
| Оперативная память | 8 ГБ |
| Диск | 50–100 ГБ свободного места |
| Графический API | Vulkan |

После перехода проекта в статус беты на стенде с 8 ГБ ОЗУ предстоит проверить запуск упакованной игры на обеих видеокартах, совместимость драйверов с текущим профилем Vulkan SM6, прохождение кампании и пики памяти при переходах. Настройки качества и частота кадров для минимума определяются этими испытаниями.

## Рекомендованные требования игры

| Компонент | Рекомендованная конфигурация |
| --- | --- |
| Архитектура | 64-разрядные процессор и операционная система |
| ОС | Windows 10 или Windows 11, 64-bit |
| Процессор | 6 или 8 ядер, 3,0 ГГц. AMD Ryzen 7, Intel Core i5/i7 |
| Оперативная память | 16 GB |
| Видеокарта | 8+ GB VRAM. Radeon RX 6800, GeForce RTX 3070, Intel Arc B580 |
| Графический API | Vulkan |
| Диск | 50–100 GB свободного места, SSD рекомендуется |
| Дополнительно | Встроенные GPU Intel вне семейства Arc не поддерживаются |

Эти требования приняты владельцем как ориентир для качества игры. Рабочая цель профиля — 1920 × 1080, High, 60 FPS. Время кадра и размер поставки проверяются в упакованной версии. Объём свободного места включает запас для обновления. На машине разработки Unreal, исходники и кэш шейдеров требуют дополнительного места и памяти.

## Профиль UE 5.7

| Область | Решение проекта |
| --- | --- |
| RHI и шейдеры | Vulkan Desktop, `SF_VULKAN_SM6`, Deferred Rendering. HLSL 2021 компилируется через DXC в SPIR-V. |
| Геометрия | Поддержка Nanite включена. При импорте флаг Nanite выбирается для конкретного Static Mesh после проверки материалов и формы. |
| Освещение | Lumen GI и Lumen Reflections с программной трассировкой по distance fields. Генерация Mesh Distance Fields включена. |
| Тени | Virtual Shadow Maps. Качество теней меняется через штатную scalability-группу. |
| Сглаживание | Temporal Super Resolution. Начальный профиль High использует 100% внутреннего разрешения. |
| Качество | Для чистого профиля пользователя значения scalability-групп равны 2 — High. |
| Аппаратная трассировка | В текущем профиле `r.RayTracing=False`, `r.Lumen.HardwareRayTracing=False`. |
| Переносимость | Общий профиль для AMD, NVIDIA и Intel Arc. Механика головоломок и сигналы питания читаются при снижении качества. |

Nanite включён для всех 13 статических мешей ФосТех, включая обе части плиты DEV-02 и корпус наручного терминала EQP-01. Тело EQP-00 использует скелетный рендер. Текст дисплея формируется отдельно на поверхности терминала. [Сравнение двух пакетов Vulkan при 1920 × 1080](FosTechNanite.md)

В установленной UE 5.7.4 секция `ShaderPlatform VULKAN_SM6` в `Engine/Config/VulkanPC/DataDrivenPlatformInfo.ini` объявляет поддержку Nanite, Lumen GI, distance fields и 64-разрядных image atomics. `VulkanShaderCompiler.cpp` выбирает для SM6 целевое окружение Vulkan 1.3. Драйвер и устройство должны поддерживать этот профиль и пройти проверку возможностей Vulkan при запуске. Профиль SM6 позволяет использовать современные возможности рендера с тем же API Vulkan. [Возможности рендер-путей Epic](https://dev.epicgames.com/documentation/en-us/unreal-engine/supported-features-by-rendering-path-for-desktop-with-unreal-engine?application_version=5.7)

High выбран как исходный бюджет под 60 FPS. Epic использует High для своего бюджета 60 FPS Lumen, а стоимость сцены Abandoned измеряется отдельно. Программная трассировка поддерживает общий путь освещения выбранных GPU. [Руководство производительности Lumen](https://dev.epicgames.com/documentation/en-us/unreal-engine/lumen-performance-guide-for-unreal-engine?application_version=5.7)

## План настроек изображения

- Добавить выбор поля зрения (FOV) в настройках игрока. Значение по умолчанию — 90°. Проверить применение в игре и восстановление выбранного значения после перезапуска.
- Добавить выбор масштабирования по возможностям конкретной машины. Для FSR 3.1 проверить путь Vulkan, в том числе на совместимых GeForce. Для ML-масштабирования FSR «Redstone» отдельно проверить поддерживаемые Radeon и требования выбранной версии SDK. AMD указывает отдельные аппаратные требования для аналитического FSR 3.1 и ML-моделей. [AMD FSR Upscaling](https://gpuopen.com/amd-fsr-upscaling/)
- Для GeForce RTX предусмотреть DLSS Super Resolution. При запуске проверять доступность технологии на активном GPU, версии драйвера и требуемых расширений Vulkan. Если дополнительный режим недоступен, использовать штатный TSR. [NVIDIA DLSS](https://developer.nvidia.com/rtx/dlss) · [Проверки поддержки и расширений Vulkan](https://developer.nvidia.com/rtx/streamline/get-started)

## Правила для ассетов и освещения

- Под Nanite в первую очередь подходят детализированные элементы сооружения, камни и статические декорации с большим числом мелких треугольников. На меше должен быть включён Nanite, а форма материала и движущиеся части проверены на целевой платформе. [Nanite в UE 5.7](https://dev.epicgames.com/documentation/en-us/unreal-engine/nanite-virtualized-geometry-in-unreal-engine?application_version=5.7)
- Для программного Lumen стены, потолки и пол собираются отдельными закрытыми модулями. Тонкие поверхности и сильный неравномерный масштаб требуют проверки Mesh Distance Fields и Surface Cache. Световые утечки проверяются по всей камере. [Технические ограничения Lumen](https://dev.epicgames.com/documentation/en-us/unreal-engine/lumen-technical-details-in-unreal-engine?application_version=5.7)
- Коллизии кубов, дверей и переносимых узлов сохраняют простые формы. Nanite и Lumen относятся к представлению и не определяют массу, проходимость, захват или логику луча.
- Для 8 GB VRAM текстуры импортируются с mip-уровнями и потоковой загрузкой. Разрешение выбирается по видимому размеру поверхности. Допустимость текстур 8K и количество материалов устанавливаются по замерам памяти.
- Обязательные сигналы питания, предупреждения радиации, метки укрытий и тексты терминала проверяются в High и при снижении GI/Reflections до Medium. Портальный Scene Capture проверяется отдельно от основного вида.

## Приёмка и замеры

В текущих игровых ресурсах нет GPU-симуляций Niagara. При запуске отдельного игрового процесса модуль Abandoned снимает регистрацию фабрики `FNiagaraGpuComputeDispatch` до создания миров. Плагин Niagara доступен редактору. В профиле также задано `fx.Niagara.AsyncGpuTrace.GlobalSdfEnabled=0` для провайдера асинхронных запросов столкновений. При вводе первого GPU-эффекта Niagara потребуется проверить освобождение кэша диспетчера при выгрузке мира и выходе из игры. [Владение ресурсами глобального поля расстояний](RenderingVerification.md#выход-из-кампании-и-глобальное-поле-расстояний)

Игровая гравитация воздействует на тела Chaos из C++. В материалах и эффектах текущего маршрута нет потребителей GPU-поля физики UE, поэтому `r.PhysicsField.EnableField=0`. При добавлении эффекта с выборкой этого поля повторите контроль переходов и замер живых буферов. [Результаты проверки Win64](RenderingVerification.md#упакованная-игра-и-память-vulkan)

[Результаты запуска от 17 ноября 2026 г., кадры и ограничения](RenderingVerification.md)

Для каждого изменения профиля собирается `AbandonedEditor`, затем запускаются сценарии `EntryCourse`, `WristTerminal`, `DoorClamp` и `Portals` с подтверждением `VULKAN_SM6` в журнале. Кадры проверяются на читаемость устройств и отсутствие повреждённого портального вида. Первый запуск нового профиля компилирует шейдеры, время компиляции учитывается отдельно.

Приёмка рекомендованных требований требует упакованной Windows-сборки на RX 6800, RTX 3070 и Arc B580 с 16 GB RAM. В отчёт входят разрешение, внутренний масштаб, драйвер, CPU/GPU frame time p95/p99, RAM/VRAM, холодный и тёплый переход и активный портал. Цель для 60 FPS — 16,67 мс на кадр. Установка и запас для обновлений должны укладываться в заявленное свободное место; фактический размер указывается по готовой сборке. [Проверки проекта](Testing.md#автопрогоны-vulkan)
