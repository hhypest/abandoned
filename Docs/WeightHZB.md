# Видимость в Weight с HZB

22 ноября 2026 г. Для Win64 Vulkan SM6 включён `r.HZBOcclusion=1`. Движок проверяет видимость примитивов по иерархической карте глубины. Глубина буфера запросов остаётся штатной — один кадр. Для принятия настройки требовались p95 ниже 7 мс и p99 ниже 8 мс без лимита, стабильные 60 к/с и корректное появление объектов при развороте, открытии двери и взгляде через портал.

## Измерение времени кадра

Две серии на одном ПК с Windows 11, UE 5.7.4, RTX 4070 Ti SUPER с 16 ГБ VRAM и 32 ГБ ОЗУ. Упакованная игра Win64 Development, профиль High, 1920 × 1080, масштаб 100%. В первой серии переключали HZB при запуске одного пакета. Во второй сравнили пересобранный пакет со штатными настройками и тот же пакет с консольным `r.HZBOcclusion=0`. Журнал подтвердил включение HZB из `SystemSettingsIni`. В отдельном GPU-профиле Weight вариант с HZB выполнял `SubmitHZB`, в контрольном кадре этот проход отсутствовал.

В каждом режиме четыре независимых процесса прошли Stairs → Weight → Stairs → Weight в порядке 0–1–1–0. После команды второго входа пропущены 120 кадров, затем взяты 300 кадров. В каждой ячейке p95 и p99 — ближайший ранг по 600 кадрам. В каждое время кадра входит ожидание VSync и лимита, если они включены. [Исходные серии, хеши CSV и отчётов](Measurements/WeightHZB.json)

| Пакет и режим | Кадр p95, 0 → 1, мс | Кадр p99, 0 → 1, мс | GPU p95, 0 → 1, мс |
|---|---:|---:|---:|
| Исходный, без лимита | 10,222 → 6,948 | 10,867 → 7,327 | 6,399 → 6,552 |
| Исходный, 60 к/с и VSync | 17,087 → 17,346 | 17,336 → 17,575 | 6,701 → 6,715 |
| Пересобранный, без лимита | 10,381 → 6,830 | 11,131 → 7,203 | 6,373 → 6,424 |
| Пересобранный, 60 к/с и VSync | 17,145 → 17,169 | 17,570 → 17,480 | 6,727 → 6,723 |

В пересобранном пакете HZB при лимите дал в среднем 60,007 к/с. Самый длинный из 600 измеренных кадров занял 18,043 мс.

В первом опыте два отдельных p95 без лимита составили 7,04 и 6,78 мс. В пересобранном пакете оба повтора прошли порог — 6,82 и 6,84 мс. Средняя частота без лимита составила 165,0 к/с с аппаратными запросами и 162,3 к/с с HZB. Выигрыш приходится на длинные кадры. Проверка ограничена испытанным адаптером. Проверка на машине с 8 ГБ системной памяти запланирована на бету.

## Видимость в движении

Контроль и HZB снимались по два раза при фиксированном шаге 60 Гц. На каждый запуск приходится 78 кадров. Для независимого эталона повторены те же сцены с отключёнными запросами видимости. Проверены 22 кадра разворота, включая первый после поворота на 180° и последовательность шагов по 15°, все 53 кадра открытия двери, зажатый створкой куб, первый и установившийся вид через портал. Прохождение портала проверено игровым сценарием. [Контроль, HZB и усиленная разность](Images/Weight-HZB-Visibility.jpg)

На кадрах 20–22 при HZB кромка поверхности за створкой видна в тот же момент, что и в эталоне. В области 420 × 160 пикселей среднее абсолютное расхождение с эталоном составило 0,22–0,26 уровня RGB из 255 в двух повторах HZB. При аппаратных запросах диапазон составил 1,07–1,60. Это объясняет тонкую линию на разности двух вариантов при открытии двери. На разворотах отсутствия кубов, плиты или разметки не обнаружено. Вид через портал присутствует уже на первом кадре. [Кадры двери 20–22 в масштабе 1:1](Images/Weight-HZB-Door.jpg)

После упаковки со штатным HZB повторно прошли DoorClamp, Portals, EntryCourse и WristTerminal. Все 78 снимков из проверки видимости пересобранного пакета сопоставлены с эталоном. В первом и установившемся кадрах портала не было пикселей с разностью более 32 уровней хотя бы в одном канале относительно эталона.

## Воспроизведение

Укажите в `$pkg` каталог `Windows` упакованной игры. Первую и вторую команды выполните отдельными сериями для `$h` в порядке 0, 1, 1, 0. Для проверки штатного профиля опустите `-HzbOcclusion`. Время измеряется отдельно от покадровой съёмки.

```powershell
./Scripts/Measure-VulkanPackage.ps1 -PackageRoot $pkg -Scenario Travel -HzbOcclusion $h
./Scripts/Measure-VulkanPackage.ps1 -PackageRoot $pkg -Scenario Travel -StockDisplay -HzbOcclusion $h
./Scripts/Invoke-UeVerification.ps1 -PackageRoot $pkg -Capture -Scenario DoorClamp,Portals -OcclusionQueryFrames 1 -HzbOcclusion $h
```
