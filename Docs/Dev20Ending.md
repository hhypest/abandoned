# Потеря DEV-20

DEV-20 — единственный узел, с которым герой может эвакуироваться. В Development-сборке маршрут открывается через **M → Load DEV-20 Route**. Возьмите узел на **E**. Повторное **E** позволяет положить его в мире и подобрать снова. **ЛКМ** с узлом в руках открывает подтверждение с объяснением последствий. Начальный фокус стоит на «Оставить в руках». **Esc** также возвращает к игре с тем же предметом.

«Выбросить навсегда» завершает эту попытку эвакуации. Экран гаснет. Слышны кобура, реплика героя «Я не смог.» и одиночный выстрел за кадром. У каждого звука есть русский субтитр. «Вернуться на станцию» начинает новую попытку с единственным узлом в гнезде. Случайное падение или штатная передача узла между камерами обрабатываются прежними сценариями.

## Снаряжение и звук

Пистолет M1911 от Xeradev закреплён на поясе скафандра. Для сцены использованы два фрагмента **200 Free SFX** от HomkaSFX. В выдаче есть звуки обращения с предметами. Для финального звука обработан короткий щелчок из этого же набора. В локальной контрольной сборке реплику читает временный синтезированный голос. ## Сборка с локальными выдачами Fab

В публичном репозитории находятся код концовки, субтитры, импортёр и титры. Модель и фонограмма хранятся локально у владельца. В сборке без этих пакетов концовка работает с субтитрами. Для сборки с экипировкой нужны исходные выдачи из библиотеки владельца и WAV реплики «Я не смог.» длительностью до 1,65 с.

Из корня проекта выполните команды в PowerShell с Python 3.11 или новее, NumPy и собранным редактором UE 5.7.4. Подставьте пути к редактору, двум архивам и однофразной записи.

```powershell
python Scripts/PrepareDev20Ending.py $pistolZip $soundUnityPackage $lineWav
& "$ueRoot/Engine/Binaries/Win64/UnrealEditor-Cmd.exe" "$pwd/Abandoned.uproject" "-ExecutePythonScript=$pwd/Scripts/ImportDev20Sidearm.py" -unattended -nosplash
```

Первый шаг сверяет SHA-256 обеих выдач и извлекает выбранные файлы в `AssetSource/Dev20Ending`. Второй сохраняет игровой меш, материал и звук в `Content/AbandonedLocal/Dev20Ending`. При упаковке Unreal включает эту папку в игру. [Подготовка исходников](../Scripts/PrepareDev20Ending.py) · [Импорт в Unreal](../Scripts/ImportDev20Sidearm.py)

## Проверка

```powershell
./Scripts/Invoke-UeVerification.ps1 -PackageRoot $packageRoot -Scenario Dev20Discard,Dev20,Dev20Recovery -Capture
```

Сценарий поднимает узел, открывает предупреждение, отменяет бросок, подтверждает вторую попытку и захватывает кадр с репликой. После возврата он проверяет наличие одного свободного DEV-20 массой 34 кг в гнезде станции. Два соседних сценария проверяют обычную передачу и восстановление после случайной потери.
