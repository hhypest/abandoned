# A‑07. Повторный вход в Weight с моделями Meshy

На конфигурации с 32 ГБ после замены моделей ФосТех p95 кадра перехода вырос с 80,546 до 82,407 мс. P95 первого полного кадра снизился с 15,785 до 13,405 мс. Медиана кадра перехода снизилась с 75,509 до 73,302 мс. Улучшение p95 перехода на этом комплекте не подтвердилось. Резерв остаётся диагностическим. Проверка на машине с 8 ГБ ОЗУ остаётся открытой.

## Время кадра

По 33 повторных входа в каждом режиме. Все значения в миллисекундах. Для строки о следующих 120 кадрах сначала взят самый долгий кадр каждого посещения.

Основное время повторного входа пришлось на `FlushAsyncLoading` внутри `Training_InitGame`: медиана составила 51,838 мс в A и 50,811 мс в B. Учитывается объединение интервалов на игровом потоке без повторного сложения вложенных вызовов. Следующий предмет разбора — ожидаемые в этих интервалах пакеты ресурсов и возможность загрузить их до перехода. Трассы этой серии не устанавливают стоимость отдельного меша или текстуры.

При первом входе каждого из трёх процессов кадр перехода занял 75,944–77,522 мс без резерва и 75,340–80,839 мс с резервом. Это первое посещение камеры в процессе с новым профилем пользователя. Кэш ОС между запусками сохранялся. [Все 72 посещения](Measurements/A07-MeshyReserveTiming.csv)

При повторных входах из резерва выдано 74–128 страниц по 64 КиБ. Остаток при закрытии составил 0–11 страниц. Для каждого входа CPU-трасса подтверждает закрытие в конце первого полного тика, а журнал — равенство числа принятых страниц сумме выданных и возвращённых.

## Условия и воспроизведение

Windows 11 x64, i5-14400F, RTX 4070 Ti SUPER, драйвер 621.24, 32 ГБ установленной ОЗУ. Windows видит 31,85 ГиБ. Объём памяти машины записан в Run.json. Ограничение ОЗУ и искусственная нагрузка на память в этой серии не применялись.

Один упакованный Win64 Development билд UE 5.7.4, Vulkan SM6, Binned2, 1920 × 1080, масштаб 100%, VSync и ограничитель FPS отключены. SHA-256 игрового EXE `2dbb1b35f8d032732a96b90c7ecf0ba0d78def35f5b63d1e07ee800292c883e7`, контейнера игровых ресурсов Abandoned-Windows.ucas `2fe7575824427df8e0dfd39d6fb98ba5a6525a13772a80be4e57327ae85b23f9`. Все процессы используют одни и те же [модели Meshy](Assets.md#фостех-во-входном-контуре).

A — 0 страниц, B — до 128. Порядок процессов A1, B1, B2, A2, B3, A3. В каждом процессе 12 посещений Weight с возвратом через Stairs. Первое посещение каждого процесса исключено из основной серии. P95 — 32-е из 33 упорядоченных наблюдений. Методика, патчи движка и экспорт событий описаны в [предыдущем опыте](A07MapReserve.md). Для разбора CPU дополнительно экспортированы таймеры `Training_InitGame` и `FlushAsyncLoading*`. Обе ветви проверены в одном исполняемом файле, режим задаёт параметр запуска.

```powershell
foreach ($limit in 0, 128, 128, 0, 128, 0) {
    ./Scripts/Measure-VulkanPackage.ps1 -PackageRoot $package -WeightVisits 12 -TraceTravel -MapPageReserve $limit
}
```
